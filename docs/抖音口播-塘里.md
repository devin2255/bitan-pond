# 《塘里》抖音口播

建议自然讲述，预计约 2 分 30 秒至 3 分钟；画面按口播依次展示真实操作。

我在电脑桌面上养了一池鱼，还顺手把两个好兄弟放了进去。

平时他们躺在荷叶上摸鱼，可一放音乐，画风直接变了……

这是我自己做的一款 Windows 桌面应用，叫《塘里》。按一下 F11，就能把池塘铺到桌面图标下面。打开电脑，鱼就在荷叶之间慢慢游，你原来的桌面快捷方式也还能正常使用。

池塘里的鱼，可不是复制粘贴的一条。锦鲤、金鱼、兰寿、孔雀鱼、斗鱼……每种养多少条，你可以自己设置。鼠标靠近，它们会游开；在水面点一下，就能撒鱼粮。

旁边还有青蛙和乌龟，各忙各的，像一口真的小池塘。

你还可以亲手画一条属于自己的锦鲤，给它设计颜色和花纹，再放进池塘，看它跟其他鱼一起游、一起抢食。想知道谁最能吃？还有吃鱼粮排行榜。

这口池塘还会看天气、过四季。选择城市或者使用当前位置，就能看到当地天气。外面下雨，池塘里也会落下雨点；到了下雪的时候，植物会慢慢积雪。

春天有嫩叶和蝌蚪，夏天荷花开放、蜻蜓飞过；秋天荷叶慢慢枯黄，冬天就剩莲蓬和枯草。白天和夜晚，池塘的光线也会跟着变化。

不过，最让我忍不住多看两眼的，还是住在荷叶上的两位好兄弟。

平时他们一个躺着翘二郎腿，一个穿着黑背心，悠哉悠哉地待在荷叶上。你还可以给第一位换上东北大花袄。

要是看他们太闲，鼠标点一下，鞭子一挥，人就掉进池塘；然后他们会自己蛙泳找一片空荷叶，再慢慢爬上去。想清静一点，也能把人物单独关掉。

更有意思的是，用支持系统媒体控制的播放器放首歌，两位好兄弟就会跳下荷叶，换上美人鱼造型，游到池塘中间一起表演。

鱼群也会游过来，随着音乐变换动作和队形，排成圆圈、爱心、荷花、双环，甚至漩涡。暂停音乐，鱼群会散开，两人也会各自游回荷叶。就算关掉人物，鱼群也能单独表演。

它不需要你一直盯着玩。工作累了，撒一把鱼粮，看几条鱼游过去；心情烦了，看看下雨的池塘；想找点乐子，就请好兄弟出来表演。

如果这口池塘放在你的电脑里，你最想养什么鱼？还想加什么有趣的玩法？评论区告诉我。
