# 好兄弟音乐表演素材

- `web/boss-show-dive-v2.png`：使用 OpenAI imagegen，根据用户提供的照片和原有角色素材生成俯视 4×2 跳水动作图。提示要保持戴眼镜的面部、白背心和深色短裤，从躺姿经过坐起、蹲下到跃入水中，人体连贯且每格留出透明边距；随后要求移除背景和阴影，保留每一帧与姿势。
- `web/boss-show-dance-v1.png`：使用 OpenAI imagegen，根据同一照片及角色参考图生成俯视 4×2 花样游泳动作图。提示保持人物外观，采用展开手臂、屈腿、抱膝、舒展等连续姿态，透明背景，不附带荷叶、文字或水面。

素材仅用于当前本地产品角色。动画运行时以连续位置插值和邻帧过渡播放，水纹由画布绘制。
