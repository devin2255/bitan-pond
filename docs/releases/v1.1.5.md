# 塘里 v1.1.5

- 新增 Windows 安装包，安装后可以在开始菜单搜索“塘里”，也可以在系统设置中卸载；原来的便携版仍可使用。
- 修复更新后可能无法看到程序的问题：新更新器会显示更新进度，校验后重新显示窗口；更新失败时尝试恢复旧版并提示原因。旧版便携程序更新成功后会尝试创建开始菜单入口。遇到旧版无法重启的情况，可直接下载安装版，池塘设置会保留。
- 新增自动性能适配：根据实际流畅程度渐进调整渲染细节，性能恢复后逐步提升；也可在池塘设置中手动选择画质优先或流畅优先。不会自动减少鱼的数量或关闭天气、人物及互动。
- 优化水面和荷叶绘制、鱼群摆尾及天气粒子，修复低帧率下鱼游得越来越慢的问题。

安装版与便携版会使用同一份本地池塘设置。不同配置和显示器的表现可能不同；多屏及低配置设备仍建议以实机效果为准。
