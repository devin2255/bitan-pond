# 塘里 v1.1.3

- 官方与镜像更新源统一验证《塘里》的签名清单，签名绑定版本号和更新包哈希；未签名或被篡改的清单不会用于安装。
- 更新检查使用官方地址、三条公共镜像及旧版兼容地址。单个地址无响应时会尝试其他地址；更新包仍可并行分片下载并校验。
- 检查更新与下载分开设置超时：下载保持空闲检测，慢速但持续传输不会因固定总时长被中断。
- 发版时自动核验 EXE 内部版本、签名、分片、地址和远端附件，再发布兼容旧版的更新清单。

公共镜像的可用性和速度会因地区、网络及服务状态变化。v1.1.2 可以通过已有镜像更新到本版；无法直连 GitHub 且尚未使用镜像更新的旧版用户需要先手动下载新版。
